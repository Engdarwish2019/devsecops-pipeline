# Security policy

This is a demonstration project. If you find a vulnerability, please open a
[private security advisory](https://github.com/Engdarwish2019/devsecops-pipeline/security/advisories/new)
instead of a public issue.

Every change goes through secrets scanning, SAST, dependency audit, container and IaC scanning,
DAST and image signing before it can be deployed. See the README for the full pipeline.
